# 零基础部署 VitePress 真实踩坑复盘

事实上，有关于这个作品，极大程度上都是依赖于ai的，作为一个零基础学生，这次的博客部署过程远比写代码本身艰难。但即使在AI辅助下面，我依然发现了一些困境，以下是总结。

## 1. 本地环境权限报错
在 Windows PowerShell 中运行命令时遭遇 `UnauthorizedAccess`。
**解决**：切换至 Command Prompt (CMD) 绕过权限限制。

## 2. GitHub 网络阻断
尝试推送到 GitHub 时遭遇 `ERR_CONNECTION_RESET`，无法连接。
**解决**：果断切换至 Gitee 平台完成代码托管，保障进度。

## 3. Gitee Pages 个人服务下线
准备部署时发现 Gitee Pages 个人版已不可用。
**解决**：尝试 Netlify 替代，但因网络风控无法注册。

## 4. 腾讯云 EdgeOne 部署与路径修复
最终采用腾讯云 EdgeOne 部署。
**解决**：页面样式丢失后，排查出 `base` 路径与 EdgeOne 根目录层级冲突，修改配置重新构建，最终公网访问成功。

## 总结
虽然ai在这个时代能辅助甚至代替计算机学生进行一些代码性的操作，但在实际过程中所面临的问题却远远不止复制粘贴。但在使用ai的同时，我们也意识到算法本身的神奇，又或者一些代码在实际应用上的理解，我认为这是对于一个在AI时代下零基础学生所能做的，或者说所能学习的课题.而更加令人感到愉悦的是,ai本身就是代码跑出来的
